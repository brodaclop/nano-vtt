nano-vtt

nano-vtt is a minimalist virtual tabletop for playing RPGs online.

Managing images

Add image
drag image file from file explorer or paste image by pressing Ctrl+V
Select image
left click image or cycle selection via Tab key
Unselect image
right click or press Esc key
Delete selected image
press Del key

Editing images

Move selected image
left click & drag image via mouse or press keys W/A/S/D
Scale selected image
rotate mouse wheel or +/- key
Rotate selected image
press Left arrow/Right arrow key
Bring selected image to top
press Up arrow key
Send selected image to bottom
press Down arrow key
Lock/unlock selected image
press Enter key

Map operations

Pan map
middle click & drag
Zoom map
middle click & rotate mouse wheel
Measure distance between two points
right click & drag

Fog-of-war editing

Enter fog editing mode
click Edit fog button or press F key
Add fog circle
left click on map
Clear circle from fog
right click on map
Exit fog editing mode
click Finish fog editing button or press Esc key
